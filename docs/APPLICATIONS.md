# PaperManga 0.4.0: Kobo, PocketBook и Android

**Все три приложения экспериментальные и не проверены на физических устройствах.** Сборка, тесты общего ядра и запуск в эмуляторах не подтверждают работу сенсора, E Ink, сна и батареи на конкретной модели. Прошивки ESP32 устанавливаются отдельно на [сайте PaperManga](https://ikrasnodymov.github.io/papermanga/).

[Файлы выпуска 0.4.0](https://github.com/IKrasnodymov/papermanga/releases/tag/v0.4.0) · [Контрольные суммы и статусы](https://github.com/IKrasnodymov/papermanga/releases/download/v0.4.0/apps.json)

| Приложение | Область первой сборки | Программная проверка | Проверка на устройстве |
|---|---|---|---|
| Kobo | Сенсорные Kobo Linux, ARM32, совместимая установка NickelMenu | ARM-сборка, общее ядро в QEMU, FBInk CLI | **Нет** |
| PocketBook | PocketBook OS / InkView, ARM32 Linux | ARM-сборка, ядро в QEMU, события и экран через тестовую InkView | **Нет** |
| Android | Android 7.0+; ARM64, ARM32 и x86_64 | Три ABI, подпись APK, запуск и импорт через системный выбор файлов в эмуляторе | **Нет** |

PocketBook на Android использует APK. Linux-ридеры ARM64, включая InkPad One, в этот ARM32-пакет не входят. Для Kobo требуется совместимость штатной системы с NickelMenu; этот пакет не предназначен для устройств на Android или Tolino.

## Kobo

1. Установи [NickelMenu по инструкции его авторов](https://github.com/pgaskin/NickelMenu). В пакет PaperManga NickelMenu не включён.
2. Распакуй `papermanga-kobo-0.4.0.zip` **в корень USB-накопителя Kobo**, включая скрытую папку `.adds`. Получатся `.adds/papermanga/` и `.adds/nm/papermanga`.
3. Включи Wi-Fi через штатные настройки, безопасно отключи USB и запусти **PaperManga (experimental)** в NickelMenu.
4. Свои XTC / XTCH положи в `.adds/papermanga/data/Manga/`. Для сервера на Mac укажи `server=http://адрес-компьютера:8794` в `.adds/papermanga/app.conf`.

Экран выводит отдельная утилита FBInk через штатные режимы обновления. Она также определяет размер экрана и поправки координат сенсора. Если касания отображаются неверно, закрой приложение и настрой `touch_device`, `swap_axes`, `mirror_x`, `mirror_y` в `app.conf`; ориентироваться можно только после проверки конкретного ридера.

На время чтения launcher приостанавливает Nickel и возобновляет его после выхода, ошибки или сигнала завершения. **«Выход» вверху либо кнопка питания** закрывает приложение. Настройки и прогресс находятся в `.adds/papermanga/data/.papermanga/`, диагностический лог — `.adds/papermanga/papermanga.log`. Для удаления закрой приложение, удали `.adds/nm/papermanga` и `.adds/papermanga/`; сначала скопируй главы и историю, которые хочешь сохранить.

## PocketBook

1. Распакуй `papermanga-pocketbook-0.4.0.zip` **в корень USB-накопителя PocketBook**. В `applications/` появятся `PaperManga.app` и папка `papermanga/`.
2. Положи XTC / XTCH в папку `papermanga/Manga/` в корне накопителя. Подпапки можно использовать для серий.
3. Безопасно отключи USB. В штатном разделе **«Приложения»** открой **PaperManga**.
4. Wi-Fi включается в штатных настройках. Адрес сервера на Mac задаётся кнопкой **«Сеть»** в верхней панели, через клавиатуру InkView; также можно положить адрес одной строкой в `applications/papermanga/server.txt`.

Вывод экрана, касания и клавиши обслуживает штатная библиотека InkView. Пакет не содержит её копии и не меняет системные файлы. Поддержка требует ARM32 Linux и доступного `libinkview.so` с API из SDK 6.5; совместимость разных аппаратных моделей ещё не подтверждена. Физические Prev/Next листают страницы, OK открывает, Back возвращает назад.

Прогресс и настройки — `papermanga/.papermanga/`, лог — `applications/papermanga/papermanga.log`. Для удаления закрой приложение и удали `applications/PaperManga.app` и `applications/papermanga/`. Отдельную папку `papermanga/` с главами и историей можно сохранить.

## Android

1. Скачай `papermanga-android-0.4.0.apk` из выпуска или с сайта и открой файл на устройстве. Разреши установку для того браузера или файлового менеджера, которым открываешь APK.
2. В меню **⋮ → «Импорт XTC / XTCH»** выбери книгу через системный файловый менеджер. Книга копируется во внутреннюю библиотеку приложения; разрешение на доступ ко всему накопителю не требуется.
3. Листай касаниями по краям, свайпами или кнопками громкости. Центр страницы открывает меню чтения. Положение сохраняется при сворачивании и закрытии.
4. Адрес сервера на Mac — **⋮ → «Сервер и MangaLib»**. Обновления устанавливаются новым APK поверх приложения, с той же подписью.

Подходит для обычных Android-устройств и Android-ридеров с поддержкой установки APK. Специальные режимы обновления BOOX/Bigme/других E Ink устройств задаёт их система; универсального обещания быстрого E Ink обновления здесь нет. Цветная манга в этом выпуске отображается четырьмя серыми тонами.

## Каталог, главы и управление

MangaDex работает напрямую. MangaLib можно использовать через приложение PaperManga на Mac: задай адрес сервера и выбери **«MangaLib через Mac»** в строке источника каталога. Для прямого MangaLib нужна собственная сессия: Android позволяет вставить её JSON в настройках; Linux-приложения читают файл `<каталог данных>/.papermanga/mangalib` в формате, который использует приложение на Mac. Сессия не входит в установочный пакет. Функции MangaLib зависят от доступа собственного аккаунта.

Общее ядро сохраняет библиотеку, историю, каталог и настройки чтения. Главы из каталога готовятся под доступную область экрана приложения. Уже готовые XTC / XTCH отображаются с сохранением пропорций. Максимальная сторона страницы — 4096 пикселей.

Верхняя панель: **Дом, Книги, Каталог, История, Сеть, Выход**. Карточки и строки выбираются касанием; свайпы перемещают выбор. Нижняя панель даёт **Назад, OK, ◀, ▶, Меню**. Долгое OK в библиотеке открывает подтверждение удаления; само удаление требует отдельного подтверждения. Подсветка, подключение Wi-Fi и системный сон задаются средствами устройства.

## Зависимости и исходники

В `papermanga-apps-0.4.0-third-party.zip` находятся исходники и лицензии распространяемых сторонних компонентов, включая полный FBInk с вложенными зависимостями и рецепт сборки. FBInk вызывается как отдельная программа. InkView берётся из штатной системы. Исходники приложения PaperManga остаются в закрытом репозитории; публично публикуются установочные пакеты, инструкции и статусы проверки.

Основные источники: [PocketBook SDK](https://github.com/pocketbook/SDK_6.3.0/tree/6.5), [FBInk](https://github.com/NiLuJe/FBInk), [KOReader toolchains](https://github.com/koreader/koxtoolchain), [Android: системный выбор документов](https://developer.android.com/training/data-storage/shared/documents-files).
