# PaperManga 0.5.1 for Xteink X3

Not tested on a device. Lite black-and-white version: a computer prepares the chapters. The UC8253/UC8279d panels still need testing.

Install in your browser: https://ikrasnodymov.github.io/papermanga/?device=x3#install

The app image on its own does not include the bootloader or the partition table. For a first install, use the website or flash every part listed in manifest.json at its address. Do not erase NVS: it holds the factory calibration.
