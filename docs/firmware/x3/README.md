# PaperManga 0.3.0 для Xteink X3

На устройстве не проверено. Облегчённая ч/б версия: главы готовит компьютер. Панели UC8253/UC8279d требуют проверки.

Установка в браузере: https://ikrasnodymov.github.io/papermanga/?device=x3#install

Образ приложения сам по себе не включает загрузчик и таблицу разделов. Для первой установки используйте сайт или все части manifest.json с указанными адресами. Не стирайте NVS с заводской калибровкой.
