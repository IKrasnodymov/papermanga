# PaperManga 0.5.0 for Xteink X4 Classic · experimental

Not tested on a device. Picks SSD1677/UC8179/UC8279 automatically. Standalone firmware without CrossPoint alongside; the tested Classic version is available separately.

Install in your browser: https://ikrasnodymov.github.io/papermanga/?device=x4c_all#install

The app image on its own does not include the bootloader or the partition table. For a first install, use the website or flash every part listed in manifest.json at its address. Do not erase NVS: it holds the factory calibration.
