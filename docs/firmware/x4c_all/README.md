# PaperManga 0.3.0 для Xteink X4 Classic · экспериментальная 0.3

На устройстве не проверено. Автовыбор SSD1677/UC8179/UC8279. Самостоятельная прошивка без соседнего CrossPoint; проверенный вариант Classic доступен отдельно.

Установка в браузере: https://ikrasnodymov.github.io/papermanga/?device=x4c_all#install

Образ приложения сам по себе не включает загрузчик и таблицу разделов. Для первой установки используйте сайт или все части manifest.json с указанными адресами. Не стирайте NVS с заводской калибровкой.
