# PaperManga 0.3.0 для Xteink X4 ESP32-C3

На устройстве не проверено. Облегчённая ч/б версия: главы готовит компьютер. Это старый X4, не X4 Classic.

Установка в браузере: https://ikrasnodymov.github.io/papermanga/?device=x4#install

Образ приложения сам по себе не включает загрузчик и таблицу разделов. Для первой установки используйте сайт или все части manifest.json с указанными адресами. Не стирайте NVS с заводской калибровкой.
