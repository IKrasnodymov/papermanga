# PaperManga 0.5.1 for Xteink X4 ESP32-C3

Not tested on a device. Lite black-and-white version: a computer prepares the chapters. This is the older X4, not the X4 Classic.

Install in your browser: https://ikrasnodymov.github.io/papermanga/?device=x4#install

The app image on its own does not include the bootloader or the partition table. For a first install, use the website or flash every part listed in manifest.json at its address. Do not erase NVS: it holds the factory calibration.
